# 上证指数日线 v1（2026-10-04 拉取）

`sse_daily.parquet`：上证指数（000001.XSHG）日线，1990-12-19 至 2026-09-30，8,736 行。

| 字段 | 含义 |
|---|---|
| date | 交易日 |
| open, high, low, close | 点位（价格指数，不含分红） |
| volume | 成交量，**股** |

来源：新浪财经公开行情接口 `CN_MarketData.getKLineData?symbol=sh000001&scale=240`，2026-10-04 取，未做任何修改。接口不提供成交额。

## 核对
与本仓库 `data/smallcap_risk_v1_20261004/index_daily.parquet`（聚宽）在 2019-01-02 至 2026-09-30 的 1,880 个共同交易日比对：日期集合一致；开高低收最大相对误差 2.0e-6（仅小数位舍入差异）；成交量逐日完全相等（同为「股」）。1990—2018 年部分没有第二来源可以比对。

## 使用注意
- 1996-12-16 起才实行 10% 涨跌停，1995 年起 T+1；更早的数据成交量很小、制度不同，研究建议从 1997 年起。
- 成交量是股数，随市场扩容长期增长，跨年代比较请用相对量（如对自身 250 日均量的比值）。
- 最长日历间隔 20 天出现在 1999-02-09 前后（春节休市），没有缺失交易日的迹象，但未与交易所日历逐日核对。
