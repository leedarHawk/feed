# 小盘风险监测数据 v1（2026-10-04 从聚宽拉取）

用途：判断小盘/量化拥挤风险。包含股指期货基差、两融（汇总与个股）、小盘与宽基指数日线、宽基 ETF 份额。
区间：2019-01-02 至 2026-09-30，日频。本目录只发布 `.parquet`；数据源只有聚宽，没有混用其他来源。拉取与整理脚本、csv 副本和聚宽原始下载未随本仓库发布。

> 价格类字段都是**不复权**。指数是价格指数（不含分红再投），所以基差里含有预期分红的影响，没有做修正。

## 1. 股指期货

| 文件 | 说明 |
|---|---|
| `futures_contracts` | 合约表，345 个（IM 2022-07 起，IC/IF/IH 2019 起的存量与新增合约）。`expire_date` 为到期日，`expire_estimated=1` 表示聚宽没给、按「交割月第三个周五」估的（遇休市日实际会顺延，未来的休市日无从得知）。 |
| `futures_contract_daily` | 各合约日线：`open/high/low/close/volume/money/open_interest`（成交额元，持仓量手）。已去掉聚宽的 8888/9999 连续合约。 |
| `futures_continuous_daily` | 聚宽的 8888（加权连续）与 9999（主力连续）合约日线，换月当天有价格跳变，只作参考。 |
| `futures_dominant_daily` | 聚宽 `get_dominant_future` 逐日给出的主力合约（`product, date, dominant_contract`）。IM 首日 2022-07-22 没有主力，已缺行。 |
| `futures_basis_by_contract` | **逐合约基差**，每个交易日、每个产品、每个未到期合约一行。 |
| `futures_basis_dominant_daily` | 聚宽「主力合约」的基差，每个产品每天一行（`futures_basis_by_contract` 里 `is_dominant=1` 的部分）。 |
| `futures_basis_oi_top_daily` | **持仓量最大合约**的基差，每个产品每天一行（`is_oi_top=1` 的部分）。聚宽的「主力」约三成交易日不是持仓量最大的合约，**研究时更推荐这张**，见下。 |

产品与现货指数：IM→中证1000（000852）、IC→中证500（000905）、IF→沪深300（000300）、IH→上证50（000016）。

### `futures_basis_by_contract` 字段
| 字段 | 含义 |
|---|---|
| `date, product, contract` | 日期、产品、合约 |
| `expiry_rank` | 当日按到期日排序：1 当月，2 次月，3 下季，4 隔季 |
| `expire_date, expire_estimated, days_to_expiry` | 到期日、是否估计、距到期的日历天数 |
| `fut_close, index_close` | 期货收盘、现货指数收盘 |
| `basis_pts` | 基差点数 = 期货 − 指数，**负数是贴水** |
| `basis_pct` | 基差 % = 期货 / 指数 − 1 |
| `basis_annualized_pct` | 年化基差 % = 基差% ÷ 距到期天数 × 365。到期前几天会被放大到几十个百分点，**距到期 ≤5 天时别用**；到期日当天为空 |
| `open_interest, volume, money` | 该合约当日持仓、成交量、成交额 |
| `is_dominant` | 是否为聚宽当日主力合约 |
| `is_oi_top` | 是否为当日持仓量最大的合约 |

**聚宽「主力」与持仓量最大不一致**：逐日比较，IC 623/1880、IF 503/1880、IH 440/1880、IM 392/1018 个交易日两者不是同一个合约（约 23%~33%）。例：2026-09-30 聚宽主力是 IM2610（持仓 8.8 万手，基差 −0.11%），持仓最大的是 IM2612（持仓 24.9 万手，基差 −1.78%）。两者的绝对基差相差一个数量级（距到期天数不同），比较时请看年化基差或固定 `expiry_rank`。

**哪个「主力」更准：没有标准答案，三种口径互相不一致。** 我用 SuperMind 的 `get_futures_dominate` 在 2022-07 至 2026-07 之间均匀抽了 30 个日期（IC、IM 各约 30 个，共 59 组），与持仓最大合约、聚宽主力对比：

| 对比 | 一致的组数 |
|---|---|
| 聚宽主力 = 持仓最大 | 34 / 59 |
| SuperMind 主力 = 持仓最大 | 31 / 59 |
| 聚宽主力 = SuperMind 主力 | 44 / 59 |

不一致几乎都出在换季月前后：两家平台都比持仓量更晚切到下一个季月合约（例如 2023-03-28 两家都还在 IC2304，持仓最大的已是 IC2306）。SuperMind 有时比聚宽更早停在近月（例如 2022-07-22 SuperMind 是 IC2208，聚宽和持仓最大都是 IC2209）。**只有「持仓最大」是可以用本目录原始合约数据复现的口径，所以研究基差优先用 `futures_basis_oi_top_daily` 或固定 `expiry_rank`，不要依赖平台给的「主力」。**

核对：2026-09-29 IM 主力 IM2610 基差 −9.35 点（−0.13%），IC −15.23 点（−0.20%）。**没有和中金所官网逐日比对**；聚宽的主力切换时点可能与交易所口径不同，换月当天基差会有跳变。

## 2. 两融

| 文件 | 说明 |
|---|---|
| `margin_total_daily` | 全市场汇总，沪（XSHG）深（XSHE）分开，每交易日每所一行。`fin_value` 融资余额、`fin_buy_value` 融资买入额、`sec_volume` 融券余量（股）、`sec_value` 融券余额、`sec_sell_volume` 融券卖出量、`fin_sec_value` 融资融券余额，金额单位元。 |
| `margin_total_combined_daily` | 沪深合计，只保留**两所都有数据**的日子（深市晚一天公布，所以比汇总表少最后一天）。含 `fin_value_sh / fin_value_sz` 便于拆分。 |
| `margin_stock_daily_<年>` | 个股融资融券日数据，按年拆分，见下。 |

### `margin_stock_daily` 字段
`date, code, fin_value`（融资余额）、`fin_buy_value`（融资买入额）、`fin_refund_value`（融资偿还额）、`sec_value`（融券余额）、`sec_sell_value`（融券卖出额）、`sec_refund_value`（融券偿还额）、`fin_sec_value`（融资融券余额）。金额单位元。
只含有两融记录的股票和日期；非标的股票没有行，**不是缺数据**。代码范围是本地 `stock_price` 里出现过的全部代码（含已退市）。
规模：487 万行，3,797 只股票，2019-01-02 至 2026-09-29（聚宽个股两融最新到 09-29）。**按年拆成 `margin_stock_daily_2019.parquet` … `margin_stock_daily_2026.parquet` 共 8 个文件**（整表 112MB，超过 GitHub 单文件 100MB 上限），各文件按 (code, date) 排序，合计行数与整表一致。
核对：逐日把个股融资余额加总，与 `margin_total_combined_daily` 的融资余额比，覆盖 87%~96%（2019 年约 87%，2026 年约 95%）。差额应是 ETF 等非股票标的，这是我的推测，没有逐项核实。个股没有重复的（代码, 日期）。

## 已知限制
- 来源是聚宽，没有和交易所官网逐日比对。基差抽检了最近几天，其余只做了行数、区间和一致性检查。
- 价格口径不复权；基差未剔除分红影响。
- 股指期货 IM 只有 2022-07-22 以后的数据。
- 日频、收盘后更新。深交所的两融和 ETF 份额晚一个交易日，最新一天可能不全。
